# manifest-audit

The manifest-audit project's own terms. Lab-wide terms (Factory, Ticket and the rest) are in the [root glossary](../../GLOSSARY.md).

## Language

**Auditor**:
The program in this Project that reads local files and reports Findings.
_Avoid_: Scanner, fuzzer, red team

**Finding**:
One match of one Rule in one file. A match is a hint, not proof.
_Avoid_: Alert, vulnerability, Verdict

**Rule**:
A named heuristic this Project documents.
_Avoid_: Project check, Factory check
