# Factory scripts run from the default branch, and agents never hold a GitHub token

Review and Rework run on `pull_request_target`, so the workflow and the `factory/` scripts always come from the default branch, and the PR's code is checked out to a separate directory as data for the agent. Every factory job splits into steps that hold the App token and run no agent, and agent steps that hold only the Claude Code login. On plain `pull_request` a PR's own workflow file runs with the secrets, so a PR, the factory's own included, could rewrite the brake that judges it; and an agent holding a GitHub token could push, merge or relabel past the brakes. The cost is that a change to the factory only takes effect after it merges, and that `pull_request_target` must keep excluding fork PRs, because it runs with secrets.
