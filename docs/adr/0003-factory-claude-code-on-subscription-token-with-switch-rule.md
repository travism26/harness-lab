# Factory Claude Code on the subscription token, with a switch rule

While only the owner's work is involved, the factory's Claude Code runs on the owner's subscription token, which costs nothing extra on top of the plan. It switches to an OpenRouter key before anyone else's issue or PR is acted on, before an unattended scheduled job runs, or if it strains subscription usage. The rule is written in the repo's factory doc. This is the one place a subscription token is used, and only for Claude Code itself, never the harness (see [0002](../../projects/harness/docs/adr/0002-openrouter-only-provider-and-sole-credential.md)); the terms question is on the list of facts to verify in post 0.
