# harness-lab

## Coding standards

Before building, changing or reviewing code, or writing a Ticket, read `CODING_STANDARDS.md`: Lab-wide rules for project layout, dependencies and paths.

## Agent skills

### Issue tracker

Issues live in GitHub Issues for `travism26/harness-lab` (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: `GLOSSARY-MAP.md` at the repo root lists the lab-wide `GLOSSARY.md` and one glossary per project under `projects/<name>/`. Lab-wide decisions are in `docs/adr/`; a project's are in `projects/<name>/docs/adr/`. See `docs/agents/domain.md`.
